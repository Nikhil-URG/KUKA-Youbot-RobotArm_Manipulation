\section{Introduction}

This report presents the statistical evaluation of the KUKA youBot arm's performance based on the combined preprocessed data from all groups. The analysis focuses on finding the accuracy and precision of the robot arm, checking if the final object poses follow a Gaussian distribution, and evaluating the effects of object size and placing pose on these metrics. The data includes three object sizes (small, medium, large), allowing comparisons across sizes and directions (left, straight, right).

\section{Data Transformation}

To align the coordinate frames between the robot (YouBot) and the external sensor (OptiTrack), a coordinate transformation was applied. The world origin [0, 0, 0] in the robot frame corresponds to the point [-212.40, 76.17, 103.15] in the OptiTrack frame. To transform YouBot coordinates (robot frame) to the OptiTrack frame for alignment, the offset vector [-212.40, 76.17, 103.15] was added to the YouBot x and y positions. The z-coordinate offset is noted but not used in the 2D plotting and analysis.

This transformation was implemented in the Python scripts using pandas operations on the matched data. The purpose is to align the frames so that positions from both sensors can be directly compared in the same coordinate system. This has implications for the analysis, as it allows meaningful computation of distances and variances between internal (YouBot) and external (OptiTrack) measurements, improving the assessment of robot accuracy and precision.

\section{Data Analysis Methodology}

The key steps of performing the analysis are:

\begin{itemize}
    \item Loading OptiTrack (external) and YouBot (internal) data from respective folders.
    \item Segregate data, based on timestamps, sizes, and directions.
    \item Applying coordinate transformation to YouBot data to align with OptiTrack frame (as described in Section II).
    \item Separating internal (YouBot, transformed) and external (OptiTrack) poses.
    \item Computing accuracy as the mean L2 norm distance between YouBot and OptiTrack positions for each group.
    \item Computing precision as the mean standard deviation of YouBot x and y coordinates.
    \item Generating scatter plots for OptiTrack data, YouBot data, and combined transformed data.
    \item Generating combined plots with arrows for orientation.
\end{itemize}
The analysis was performed using Python scripts: \href{https://github.com/Nikhil-URG/KUKA-Youbot-RobotArm_Manipulation/blob/Exp6_results/transformed_data_plotter.py}{Transformed data plotter} and \href{https://github.com/Nikhil-URG/KUKA-Youbot-RobotArm_Manipulation/blob/Exp6_results/separate_plots_generator.py}{Seperate Plot Generator} for generating separate scatter plots. 

\section{Accuracy and Precision Results}

After applying the coordinate transformation to align YouBot data with the OptiTrack frame, small objects show average positioning accuracy of 32.31 cm, while medium objects show 29.04 cm and large objects show 29.22 cm. The precision (mean standard deviation of OptiTrack positions) ranges from 0.00 to 1.18 cm.

The OptiTrack positions show low variance, indicating high precision in the external measurements. Comparisons across object sizes show that accuracy improves slightly for smaller objects, while precision is generally consistent but varies by direction. This discrepancy is seen because the gripping point for small object is almost at it's center of gravity, hence when small object is placed by the end-effector there is very little wobble but when it comes to large or medium sized object, there is a significant wobble causing this inaccuracy with larger objects.

\section{Effects of Size and Position}

The data includes three object sizes (small, medium, large), allowing analysis of size effects. Small objects show average positioning offsets of 32.31 cm, compared to 29.04 cm for medium objects and 29.22 cm for large objects. Precision varies by direction, with straight directions generally showing higher precision (lower standard deviation) than left or right. Positional effects are evident, with left and right directions showing higher variability in x-coordinates compared to straight.

\section{Statistical Significance}

The precision values show notable differences across directions, with straight directions exhibiting lower standard deviations (higher precision) compared to left and right. Size effects are present, with small objects showing the best accuracy. These differences suggest that both object size and placement direction influence robot performance.


\section{Gaussian Distribution Analysis}

To determine if the final object poses follow a Gaussian distribution, histograms were generated for X and Y position coordinates for each condition. Gaussian fits were applied, and p-values were analysed.

The analysis shows that Youbot data exhibits zero variance (deterministic positions), while OptiTrack data shows varying degrees of normality depending on the condition.

\section{Levene’s test}

A Levene’s test was conducted to evaluate the effects of object size and placing pose on the robot's precision (variance in final position).

\textbf{Effect of Size:} The test yielded a p-value of 0.282, indicating no statistically significant difference in precision across object sizes. We conclude that the mass/shape of the object does not significantly impact the robot's repeatability.

Effect of Pose: The test yielded a p-value of $2.66 \times 10^{-19}$, indicating a highly significant difference. This suggests that the robot's precision is heavily dependent on the trajectory and final arm configuration (Left, Right, or Straight).



\textbf{Levene's test results}



 STATISTICAL SIGNIFICANCE (Levene's Test)

Hypothesis: Variances (Precision) are equal across groups.

1. Effect of OBJECT SIZE (Large, Medium, Small):
   Levene Statistic = 1.2687
   P-value          = 2.8170e-01
    RESULT: NOT Significant. Precision is consistent across sizes.

2. Effect of PLACING POSE (Left, Right, Straight):
   Levene Statistic = 44.8789
   P-value          = 2.6602e-19
    RESULT: SIGNIFICANT. Changing direction AFFECTS precision.

COMPARISON OF EFFECTS:
Placing POSE (Stat=44.88) has a larger effect on variance than Size (Stat=1.27).



\textbf{Conclusion of the test:} The change in Placing Pose has a significantly larger effect on the robot's performance along with the change in Object Size.
