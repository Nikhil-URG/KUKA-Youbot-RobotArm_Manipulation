## Project Overview

This project analyzes the accuracy and precision of a KUKA youBot arm based on data from a pick-and-place experiment. The experiment involves a KUKA youBot arm, an OptiTrack motion tracking system, and objects of three different sizes (small, medium, and large).

The project uses Python for data processing, analysis, and visualization, and LaTeX for the final report.

### Key Files

*   `main.tex`: The LaTeX source for the project report.
*   `convert_rosbags.py`: A Python script to convert ROS bag files (the raw data from the youBot) into CSV files.
*   `data_plotter.py`: A Python script that processes the data from a single group (Group3), generates plots, and calculates statistics.
*   `combined_data_plotter.py`: A Python script that combines and processes the data from all four groups, generates plots, and calculates statistics.
*   `preprocessed_data.csv`: A CSV file containing the preprocessed data from Group3.
*   `combined_preprocessed_data.csv`: A CSV file containing the combined preprocessed data from all groups.
*   `*.png`: Image files containing the plots generated by the Python scripts.
*   `Group*/`: Directories containing the raw data for each group.

## Building and Running

### 1. Convert ROS Bags to CSV

To convert the ROS bag files to CSV, you need to modify and run the `convert_rosbags.py` script.

1.  **Install dependencies:**
    ```bash
    pip3 install pandas tqdm rosbags
    ```
2.  **Modify the script:** Open `convert_rosbags.py` and change the `INPUT_FOLDER` and `OUTPUT_FOLDER` variables to match your directory structure.
3.  **Run the script:**
    ```bash
    python3 convert_rosbags.py
    ```

### 2. Generate Plots and Preprocessed Data

To generate the plots and preprocessed data, you need to run the `data_plotter.py` and `combined_data_plotter.py` scripts.

1.  **Install dependencies:**
    ```bash
    pip3 install pandas numpy matplotlib
    ```
2.  **Run the scripts:**
    ```bash
    python3 data_plotter.py
    python3 combined_data_plotter.py
    ```

### 3. Compile the LaTeX Report

To compile the LaTeX report, you need a LaTeX distribution (e.g., TeX Live, MiKTeX).

1.  **Compile the .tex file:**
    ```bash
    pdflatex main.tex
    ```

## Development Conventions

*   The project uses Python 3.
*   The Python scripts use the `pandas`, `numpy`, and `matplotlib` libraries for data manipulation and visualization.
*   The `rosbags` library is used for working with ROS bag files.
*   Data is stored in CSV format.
*   The final report is written in LaTeX.
